# Fonts

`fjalla-one-latin.woff2` and `fjalla-one-latin-ext.woff2` are Fjalla One by Sorkin Type, downloaded from Google Fonts and served from here so `site-nav.css` can declare them under the name "GRJ Display" for every weight. Fjalla One has a single weight, and this stops browsers from drawing a fake bold.
