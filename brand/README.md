# GRJ brand assets

Logo files for The Goaltending Research Journal. GRJ is set in Jost SemiBold (600) with 2% letter spacing and converted to outlines, so no font is needed.

| File | Use |
| --- | --- |
| grj-wordmark.svg | Main logo on light backgrounds (#9A7420) |
| grj-wordmark-dark.svg | Main logo on dark backgrounds (#E2B955) |
| grj-wordmark-mono.svg | One color, follows `currentColor` |
| grj-lockup.svg, grj-lockup-dark.svg | GRJ over "THE GOALTENDING RESEARCH JOURNAL" |
| grj-icon.svg | App and social icon; also `../logo.svg` |
| grj-favicon.svg | Browser tab, a single G; also `../favicon.svg` |

Colors (Brass & Ink, 2026-10-31): Brass #9A7420, Pewter #B3ADA0, links #85610F on paper #F8F6F0 (light) and #E2B955 on ink #0F131C (dark).
Fonts: Cinzel for headings, EB Garamond for reading, IBM Plex Sans for the interface.
