# GRJ brand assets

Logo files for The Goaltending Research Journal. GRJ is set in Fjalla One with 2% letter spacing and converted to outlines, so no font is needed. The lockup's second line is Jost Medium (500) in capitals.

| File | Use |
| --- | --- |
| grj-wordmark.svg | Main logo on light backgrounds (#4B706A) |
| grj-wordmark-dark.svg | Main logo on dark backgrounds (#A4C7C1) |
| grj-wordmark-mono.svg | One color, follows `currentColor` |
| grj-lockup.svg, grj-lockup-dark.svg | GRJ over "THE GOALTENDING RESEARCH JOURNAL" |
| grj-icon.svg | App and social icon, white GRJ on Smoke Jade; also `../logo.svg` |
| grj-favicon.svg | Small GRJ tile. The site's browser-tab icon is `../favicon.svg`, the topic-colour sunflower |

Colors (J8 Smoke Jade, Goldy 2026-11-08): Smoke Jade #4B706A with white; deep #3B5D58; tint #D9E8E5. Light pages: ground #F7F9F8, text #172120. Dark pages: ground #0D1211, panels #141C1B, text #E9F0EE, accent #A4C7C1. Moving-word gradient #C0D4D0 / #78A09A / #3B5D58. The nine topic colours are unchanged.
Fonts (Goldy 2026-11-08): Fjalla One for the logo, titles and headings; Jost for small labels; Source Serif 4 for reading; IBM Plex Sans for the interface.
